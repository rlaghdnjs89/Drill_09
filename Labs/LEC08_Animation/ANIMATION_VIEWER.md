# Drill #8 애니메이션 뷰어

`animation_viewer.py`를 실행하면 화면 중앙에서 걷기 → 뛰기 → 점프 → 공격을 차례로 재생합니다. 각 동작을 5회 반복하고 마지막 프레임에서 1초 멈춘 뒤 다음 동작으로 넘어갑니다. 네 동작이 끝나면 처음부터 계속 반복합니다. Escape 키 또는 창 닫기 버튼으로 종료합니다.

## 스프라이트 시트와 확대 표시

- `hero_sprite_sheet.png`는 1536 × 1024 픽셀, 6열 × 4행 시트입니다. 위에서부터 걷기, 뛰기, 점프, 공격 행입니다.
- 한 셀은 256 × 256 픽셀이지만 그림의 실제 너비와 높이는 프레임마다 다릅니다. 일부 검 끝은 다음 셀까지 이어지므로 `FRAME_BOUNDS`가 셀 경계를 넘는 좌표도 기록합니다. 반대로 앞 프레임에서 넘어온 고립 픽셀은 제외합니다. 이 좌표로 `clip_draw` 영역을 정하고 화면 위치를 보정합니다.
- 셀 기준 표시 크기는 592 × 592 픽셀입니다. 800 × 600 화면의 중앙에 확대해 표시합니다.
- 걷기·뛰기·점프는 각각 6프레임, 공격은 5프레임을 사용합니다. `playback_indices`는 각 동작의 프레임 수를 기준으로 5회 반복합니다.

## 실행과 확인

```powershell
python animation_viewer.py
python -m unittest test_animation_viewer.py
```

이미지를 다른 시트로 교체하면 `FRAME_BOUNDS`도 새 그림에 맞게 갱신해야 합니다.
